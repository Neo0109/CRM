# v1.8.4 Calm Workspace UI

## Summary

Refreshes the CRM visual system toward a calmer Notion/Day One style workspace while keeping the existing Leads Review workflow intact.

## Changes

- Added a generated subtle paper-texture bitmap asset for the app surface.
- Added `aesthetic-refresh.css` as a focused visual override layer.
- Reworked the desktop layout into a quiet left navigation rail plus a paper-like main workspace.
- Removed the heavy hero-image feeling from the primary CRM shell.
- Softened cards, filters, tables, chips, detail inspector, radar cards, and weekly report surfaces.
- Bumped the visible header and health endpoint to `v1.8.4`.
