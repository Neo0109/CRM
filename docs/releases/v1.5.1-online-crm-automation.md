# v1.5.1 Online CRM Automation Recovery

Date: 2026-05-26

## What changed

- Added `automations/jobs/online_daily_v3.mjs` as the production GitHub Actions generator.
- Updated `.github/workflows/sync-daily-report.yml` to run v3 online.
- The workflow now generates and syncs three outputs online:
  - `data/reports/YYYY-MM-DD.json`
  - `data/radar/YYYY-MM-DD.json`
  - `data/steam_trends/YYYY-MM-DD.json`

## Why this was needed

The previous online generator could fetch Steam candidates but dropped all leads when Steam AppDetails failed or returned incomplete data. This made the daily report, Steam trends, and CRM import look empty even though GitHub Actions was running.

v1.5.1 keeps Steam search candidates as reviewable leads even when AppDetails is unavailable, so the automation no longer collapses to zero.

## Verification

The 2026-05-26 online run generated:

- 45 scanned Steam candidates
- 45 reviewable games
- 3 push-pool leads
- 12 watch-pool leads
- 10 drop-pool leads
- Steam trend macro summary and genre signals
