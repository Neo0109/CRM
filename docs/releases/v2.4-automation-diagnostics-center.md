# v2.4 - Automation Diagnostics Center

Date: 2026-06-04

## Scope

Adds a read-only automation diagnostics center for the BD decision workspace.

## What Changed

- Adds `/api/automation-diagnostics` to read GitHub `main` artifacts for the selected report date.
- Shows daily report, industry radar, Steam trends, and automation receipt health in one page.
- Surfaces sourcing volume diagnostics, media/Bilibili source pool counts, Steam enrichment counts, sync status, warnings, and suggested recovery actions.
- Adds a sidebar entry named `自动化诊断`.
- Removes the frontend build-time daily sync side effect; report syncing remains owned by GitHub Actions daily automation and watchdog workflows.

## Boundaries

- Does not change daily sourcing rules.
- Does not change GitHub Actions schedules.
- Does not trigger generation or CRM sync from the product UI.
- Does not move the daily report sync responsibility into frontend build or product UI.
- Does not change login, user permissions, lead bucket logic, or manual review workflow.

## Version

- Product version: `v2.4`
- Health version: `v2.4-automation-diagnostics-center`
