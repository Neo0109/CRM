# v1.3.2 Detail UX Refinement

Date: 2026-05-25

## Changes

- Folded the raw `Due Date` field out of the lead detail form.
- Added a reminder note that points users to the calendar for follow-up scheduling.
- Stage dropdown values now display as `New`, `Watch`, `Active`, `Negotiating`, `Won`, and `Rejected` while keeping the stored values unchanged.
- Clarified the product rule checkboxes as `排除 / 降权规则`.
- Rule labels now show their actual meaning: `PC Early Access（排除）`, `叙事主导（排除）`, `印度团队（排除）`, and `中国能力已占位（降权）`.
- Updated the health check version to `v1.3.2-detail-ux-refinement`.

## Product Principle

Follow-up dates belong to the calendar because they are a user commitment. Lead detail should explain the project and its decision logic without creating a second, ambiguous scheduling surface.
