# v1.2.8 Review 队列处理逻辑

日期：2026-05-25

## Summary

修复 Leads Review 默认列表中已处理 lead 不消失的问题。

## Changes

- 默认 Review 队列只显示 `未处理` leads。
- 点击 `淘汰` 后，lead 会进入 `淘汰池`，并从当前默认列表中消失。
- 点击 `跟进` 后，lead 会进入 `跟进中`，并从当前默认列表中消失。
- 点击顶部 `淘汰池` / `跟进中` 指标，或手动筛选对应池子时，仍可查看这些已处理 leads。
- 更新 `/api/health` 版本号为 `v1.2.8-review-queue`。

## Notes

这是为集中 review 工作流做的行为修复：默认列表像未读邮件，只保留还需要处理的线索；处理后的线索进入对应池子。
