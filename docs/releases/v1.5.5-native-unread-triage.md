# v1.5.5 Native Unread Triage

Date: 2026-05-26

## Changes

- Restore the unread lead triage actions as native React logic instead of an `index.html` runtime script.
- In the unread queue, both the list row and detail panel now show three direct actions: follow up, watch, and drop.
- Choosing watch moves the lead into the watch pool and marks it reviewed, so it leaves the unread queue immediately.
- Choosing follow up moves the lead into the follow-up pool.
- Choosing drop moves the lead into the drop pool.
- Missing-link triage keeps the same three actions: follow up, watch, and drop.

## Why

The earlier runtime patch risked affecting the login entrypoint. This version keeps the Vite entrypoint clean and puts the workflow behavior back inside `App.tsx`, where it belongs.
