# v1.4.4 Steam macro backfill

Date: 2026-05-25

## Summary

This release fixes the empty Steam Trends page by adding macro-level Steam market reports and backfills the missing 2026-05-24 sourcing report. It also fixes the filtered lead review experience where the Missing Links metric could appear empty because the default review queue behavior hid already-reviewed rows.

## Changes

- Added Steam macro trend report support in the frontend:
  - market-level insights
  - genre signals
  - candidate/sample sections
  - visible source links for SteamDB, Popular Upcoming, Top Sellers, tags, and Steam Next Fest
- Backfilled `data/steam_trends/2026-05-25.json` and `data/steam_trends/2026-05-24.json`.
- Backfilled `data/reports/2026-05-24.json`.
- Updated `/api/leads` to sync yesterday once if it has not already been imported, then sync today before returning leads. This reduces missed daily-report imports without repeatedly overwriting older manual review work.
- Fixed review queue visibility so special filters such as Missing Links do not get overridden by the default unhandled-only queue.
- Bumped UI and health versions to `v1.4.4-steam-macro-backfill`.

- https://steamdb.info/charts/
- https://steamdb.info/charts/?sort=trending

- https://store.steampowered.com/search/?filter=topsellers

## Notes

The Steam Trends page now offers macro context first. It does not automatically import every trend item into CRM; CRM candidates remain explicit so the lead pool does not get noisy.
