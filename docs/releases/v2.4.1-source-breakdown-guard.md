# v2.4.1 Source Breakdown Guard

> Historical naming note: this file predates the stricter version-governance policy. It is a daily/sourcing automation patch record, not a product-visible `v2.4.1` release.

## Scope

- Daily sourcing automation only.
- No login, UI layout, manual workflow, product schema, or product version changes.

## Changes

- Added a domestic media/Bilibili rescue candidate path for V6.2 sourcing when strict sources are too narrow.
- Prioritized Bilibili official/developer/publisher signals over recommendation UP videos.
- Kept already-released, duplicate, stale, generic, and non-product media topics out of new review leads.
- Filtered unstable media titles such as generic numbers, development-log fragments, industry reports, version-update topics, and commentary-only topics.
- Preserved the rule that non-dropped automation leads enter the `未处理` inbox for human review.
- Improved diagnostics by reporting rescue candidate counts in low media-source warnings.
- Filtered malformed extracted URLs so truncated links do not appear as verification links.

## Verification

- Local smoke test with constrained Steam access produced 15 media/Bilibili candidates and no known bad generic media leads.
- Local Steam access was partially blocked by TLS failures, so the test intentionally verifies that the report remains valid under source degradation.
