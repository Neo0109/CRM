# v1.5 - Online Daily Automation

Release date: 2026-05-26

## What Changed

- Moved daily CRM generation from Codex desktop automation to GitHub Actions so it no longer depends on the local Windows workspace.
- Added `automations/jobs/online_daily.mjs`, a no-dependency Node.js generator that creates all three daily data files:
  - `data/reports/YYYY-MM-DD.json`
  - `data/radar/YYYY-MM-DD.json`
  - `data/steam_trends/YYYY-MM-DD.json`
- Updated `.github/workflows/sync-daily-report.yml` into a full online pipeline:
  - resolve Shanghai date
  - run the online generator
  - commit generated daily files to `main`
  - call Cloudflare Pages `/api/reports/sync` to import the daily report into Supabase CRM
- The workflow runs daily at 09:30 Asia/Shanghai and can also be triggered manually from GitHub Actions.

## Why

The previous automation depended on the local Codex workspace. On the current Windows machine, local process startup is blocked by policy, so scheduled Codex jobs could appear configured but fail to run. This release moves the actual generation and sync work to GitHub's online runner.

## Notes

- The first version uses public Steam Store/AppDetails data and stable public links. It does not require OpenAI API quota.
- Radar and Steam trend pages now get their own generated daily JSON files instead of relying on the CRM daily report alone.
- The daily report remains the source used to import suitable leads into Supabase CRM.
