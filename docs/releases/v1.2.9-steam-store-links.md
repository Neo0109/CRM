# v1.2.9 Steam Store Links

Date: 2026-05-25

## Changes

- Rewrites Steam Community app links like `https://steamcommunity.com/app/4553080/discussions/` to the canonical Steam store URL `https://store.steampowered.com/app/4553080/`.
- Keeps the CRM Steam chip focused on the store details page, so screenshots, description, developer/publisher, release window, and tags are visible immediately.
- Updates `/api/health` to report `v1.2.9-steam-store-links` after Cloudflare deploys the latest commit.

## Notes

This is a frontend safety layer for imported leads and daily reports that may contain Steam Community app URLs. SteamDB links remain unchanged.
