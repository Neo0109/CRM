# v1.2.3 AI 视觉线索助手

日期：2026-05-22

## 新增

- 线索助手支持截图 OCR / 视觉识别：用户可以直接粘贴截图、从相册选择截图，或在手机端拍照上传。
- 后端接入 OpenAI Responses API：当提交图片时，会读取截图内容，并结合用户输入的关键词或说明生成结构化 lead。
- 截图线索会自动使用 web search 顺藤摸瓜补全：优先查找 Steam 页面、SteamDB、官网/presskit、发行商官网、Discord、X/Twitter、B站、新闻稿等。
- 识别结果会直接写入 CRM，不再需要用户手动导入 JSON。
- 对识别出的游戏做基础清洗：跳过 DLC、原声带、工具、非游戏软件；链接字段保留 Steam/SteamDB/官网等，联系方式字段避免混入 Steam 商店页。
- 若找不到真实邮箱、电话、微信等直接联系方式，会至少补充可访问的 Steam 社区、官网、社媒或开发者入口，避免联系方式完全空白。

## 移动端体验

- “从相册选择”按钮使用 `accept="image/*"`，手机浏览器会唤起相册/文件选择。
- “拍照上传”按钮使用 `capture="environment"`，支持在手机端直接打开后置摄像头拍照。
- 保留桌面端直接粘贴截图能力，适合从 Steam、B站、新闻页、聊天记录中快速截图录入。

## 环境变量

Cloudflare Pages 需要新增：

- `OPENAI_API_KEY`：OpenAI API Key，建议作为 Secret 保存。

可选：

- `OPENAI_VISION_MODEL`：默认使用 `gpt-4.1-mini`，如需切换模型可在这里配置。

如果没有配置 `OPENAI_API_KEY`，线索助手会返回“缺少 OPENAI_API_KEY，无法进行截图 OCR / 视觉识别”。

## 说明

这版解决的是“截图不是附件备注，而是真正能被 AI 读懂并自动转成 CRM lead”的问题。后续可以继续把截图来源、OCR 原文、AI 检索来源做成详情页里的可折叠审计记录。
