# v2.3.5 多人登录配置恢复

## Changes

- Added `CRM_USERS_JSON` parse diagnostics to `/api/health` through `crmUsersJsonStatus`.
- Tolerates common Cloudflare paste mistakes such as a missing comma/object separator between user entries.
- Added `jojo` to local display-name fallback while preserving configured `display_name` from Cloudflare.
- Shows a configuration-specific login error when `CRM_USERS_JSON` is present but cannot be parsed.

## Verification

- Typechecked frontend and backend TypeScript projects.
- Verified the parser handles both valid multi-user JSON and the common missing-separator shape without dropping all users.
