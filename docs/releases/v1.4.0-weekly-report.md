# v1.4.0 Weekly Report

Date: 2026-05-25

## Changes

- Added a deterministic weekly report API at `/api/reports/weekly`.
- Added a top-bar `周报` workspace in the CRM UI.
- Weekly report shows:
  - total games sourced this week
  - how many entered follow-up / push pool
  - push pool and follow-up split
  - dropped count
  - pending review count
  - missing Steam link count
- Follow-up products are displayed as cards with:
  - project name, bucket, priority, region
  - basic product summary from CRM fields
  - recommendation summary from `priority_reason`, `rule_fit`, `bilibili_fit`, and `verdict`
  - Steam store link and SteamDB link when available
- Added a date picker so the user can view the report for any week by choosing one date inside that week.
- Updated health check version to `v1.4.0-weekly-report`.

## Data Principle

No OpenAI API is used. The report is calculated from existing CRM data only: `first_seen`, `reviewed_at`, `bucket`, `review_status`, `priority_reason`, `rule_fit`, and stored game links.

## Counting Rules

- `本周 Sourcing`: leads whose `first_seen` falls inside the selected Monday-Sunday week.
- `进入跟进/推进`: leads currently in `推进池` or `跟进中`, with `reviewed_at` inside the week; if `reviewed_at` is missing, `first_seen` inside the week is used as a fallback.
- `淘汰`: leads currently in `淘汰池`, with the same `reviewed_at` then `first_seen` fallback.
