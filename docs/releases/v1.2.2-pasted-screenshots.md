# v1.2.2 - 线索助手截图粘贴

发布日期：2026-05-22

## 新增功能

- 线索助手支持直接 `Ctrl+V` 粘贴截图，不需要先保存图片再上传。
- 支持从输入框或截图区域粘贴图片，并在页面内显示缩略图预览。
- 支持继续用文件选择补充图片，粘贴和上传的图片可以混用。
- 支持删除已附加截图，避免误提交。
- 单次最多附加 6 张图片，单张图片限制 8MB，降低线上请求过大的风险。

## 后端处理

- 线索助手 API 接收截图附件的名称、类型、大小、来源和图片 data URL。
- CRM 备注只记录截图元信息，不把整张图片写入 lead 备注，避免数据库记录过重。
- 仅提交截图时也会生成一条待补充的手动线索，不再出现前端可提交但后端无结果的空转。
- 从 Steam 链接录入时，如果用户没有填写联系方式，系统会自动补充 Steam 社区讨论区作为可触达入口。

## 使用口径

- 截图用于快速留存上下文；当前版本先完成粘贴、预览和提交通路。
- 如果截图里有项目名、Steam 链接或联系方式，仍建议在文字框里补一句关键词，能显著提高自动录入准确率。
