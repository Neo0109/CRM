# v1.2.6 B站风格 UI 与统计筛选

日期：2026-05-23

## Summary

刷新 CRM 视觉风格，并让顶部统计池子变成可点击的分类入口。

## Changes

- 前端页面版本号更新为 `v1.2.6`。
- `/api/health` 增加 `v1.2.6-ui-refresh` 版本标识。
- 顶部“未处理、推进池、跟进中、观察池、淘汰池、缺链接”统计卡片支持点击筛选。
- 点击统计卡片后会直接显示当前分类下的具体项目，并同步更新右侧详情。
- 清空筛选时同步重置当前选中 lead，避免详情栏和列表分类不一致。
- 更新 CRM 主界面、线索助手和手动导入入口的视觉样式。

## Notes

- 本次 UI 资产来自当前 Codex 会话生成的 B站风格 CRM 背景图。
