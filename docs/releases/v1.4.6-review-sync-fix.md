# v1.4.6 Review Sync Fix

Release date: 2026-05-25

## What changed

- Stop normal lead loading from re-syncing a daily report that has already been imported.
- Stop the `/api/reports/sync` endpoint from re-importing an already synced report by default.
- Keep a `force=1` escape hatch for deliberate manual re-syncs.
- Clear the right-side detail panel when the Missing Links queue has no visible leads left.
- Bump the visible UI label to `v1.4.6` and the health endpoint version to `v1.4.6-review-sync-fix`.

## User impact

- Previously handled push/watch/follow/drop decisions should no longer be overwritten just because the CRM page is refreshed.
- When Missing Links reaches zero, the UI should no longer show a stale lead detail such as an already dropped project.
