# v1.4.7 Pipeline Push Option

Release date: 2026-05-26

## What changed

- Added a visible `推进中` quick action for leads already in `跟进中`.
- The `推进中` action moves the lead into the existing `推进池` bucket and sets `stage` to `negotiating`, representing projects that passed ops testing and should enter deeper business discussion.
- Replaced the DOM-based pipeline action enhancer with native React quick-action rendering, so row and detail actions stay consistent.
- Kept the persisted bucket value as `推进池` to avoid migrating historical data, schemas, reports, and weekly stats.
- Bumped the visible UI label to `v1.4.7` and the health endpoint version to `v1.4.7-pipeline-push-option`.

## Root cause

- v1.4.1 documented the `推进池` funnel semantics and introduced a `push` action patch, but the `跟进中` action configuration only rendered `转观察` and `淘汰`.
- Because the old implementation used a DOM enhancer over fixed React buttons, the unused `push` action existed in code but had no visible button path.
