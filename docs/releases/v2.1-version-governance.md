# v2.1 Version Governance

Release date: 2026-06-02

## Changes

- Bumped the visible CRM version to `v2.1`.
- Added a single frontend product version source for the app shell and runtime refinement modules.
- Changed the CSS brand fallback to read `data-brand-label` instead of hardcoding a stale version.
- Pointed the Cloudflare Pages asset redirect at `main` with a fresh cache-buster instead of an old fixed commit.
- Added an HTML-level version guard so stale frontend bundles cannot render the old header label.
- Updated frontend and Cloudflare health responses to `v2.1-version-governance`.

## Context

The previous UI had several independent version patches. If one module or CSS fallback stayed at `v2.0`, the deployed page could still show the old version even after product changes shipped.
