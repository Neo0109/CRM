# v1.2.4 Leads Review 备注降噪

日期：2026-05-22

## 调整

- Leads Review 主表不再展示备注列，避免“导入日报”“线索助手输入”等流水账信息干扰人工筛选。
- 主表保留并突出“推荐理由 / 规则”列，用作 review 时的一眼判断摘要。
- 备注字段仍保留在右侧详情页，可用于人工补充私有判断、跟进记录或临时说明。
- 表格宽度略收窄，隐藏低价值备注后，主要 review 信息更集中。
- 日报自动化 prompt 增加硬约束：项目 insight 必须写入 `priority_reason`、`rule_fit`、`verdict`、`next_action`，并控制长度。

## 数据使用约定

后续日报自动化应优先把项目级判断写入：

- `priority_reason`：为什么值得看，或为什么优先级高/低，控制在 45 个中文字以内。
- `rule_fit`：是否符合国内优先、海外高视觉/强数据、排除项等规则，控制在 60 个中文字以内。
- `verdict`：一句话结论，控制在 45 个中文字以内。
- `next_action`：下一步 BD 动作，控制在 45 个中文字以内。

`notes` 只用于人工备注，不再作为 review 主视图信息源，也不要写“导入日报”“来自扫描”“线索助手输入”等流水账。
