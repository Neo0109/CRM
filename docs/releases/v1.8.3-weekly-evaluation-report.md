# v1.8.3 Weekly Evaluation Report

## Summary

Updates the weekly report to match the current Leads Review workflow and adds structured product evaluation fields.

## Changes

- Add `evaluation_grade`, `evaluation_result`, and `evaluated_at` to CRM leads.
- Add a right-side Leads Review "评测结果" section with grade options from `S` through `C-`.
- Weekly report now summarizes:
  - this week's sourced products,
  - submitted-for-test products,
  - products entering follow-up,
  - currently active follow-up products,
  - dropped products.
- Follow-up product cards now include a short follow-up summary, preferring the structured evaluation result when available.
- Exports include the new evaluation fields.
