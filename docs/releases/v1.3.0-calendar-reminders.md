# v1.3.0 Calendar Reminders

Date: 2026-05-25

## Changes

- Added a Calendar entry in the CRM top navigation.
- Added a full-screen calendar workspace showing CRM follow-up reminders and official Steam events together.
- Uses existing `due_date` as the next follow-up reminder date, so no database migration is required.
- Added quick follow-up controls for projects in `跟进中`: schedule 1 month later, 2 months later, or clear the reminder.
- Added Steam 2026 official seasonal sales, Steam Next Fest windows, and official themed fests using Steamworks Upcoming Steam Events as the source.
- Updated health check version to `v1.3.0-calendar-reminders`.

## Source

Steam official event dates are tracked from Steamworks Upcoming Steam Events:
https://partner.steamgames.com/doc/marketing/upcoming_events

## Notes

This version focuses on visual CRM reminders inside the web app. Email or external push reminders can be added later using the same `due_date` field.
