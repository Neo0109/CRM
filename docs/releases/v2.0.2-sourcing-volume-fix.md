# v2.0.2 Sourcing volume fix

- Fixed Steam keyword discovery so Chinese/domestic searches use the real `term` parameter instead of falling back to generic popular-upcoming results.
- Expanded domestic Steam discovery queries for domestic games, Demo, indie, China, guofeng, wuxia/xianxia, roguelike, deckbuilder, and management signals.
- Changed same-AppID dedupe to keep the strongest source signal, so domestic keyword and Demo sources are not masked by generic CN popular lists.
- Extended recent-report dedupe from 3 days to 45 days so stale CRM candidates do not keep returning as updates and crowd out new discoveries.
- Increased the online workflow candidate scan from 160 to 260 and enlarged the non-dropped review pool.

Root cause: the V4 rule document was ahead of the executable generator. The generator still depended too heavily on generic Steam discovery and had a search-parameter bug that weakened domestic keyword sourcing.
