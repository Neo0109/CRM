# v2.3.3 Pages Local Assets Entry

Date: 2026-06-02

## Changes

- Stopped the Cloudflare Pages shell from loading frontend JavaScript and CSS from a fixed old jsDelivr commit.
- Updated the Pages shell to load the current deployment's local `/assets/index.js` and `/assets/index.css`.
- Added `_routes.json` so `/assets/*` is served as static Pages assets instead of invoking catch-all Functions.
- Replaced the old asset redirect Function with a Pages `env.ASSETS.fetch()` fallback.

## Why

The API and health endpoint were deployed to `v2.3.2`, but the browser was still executing an older frontend bundle from commit `ec6567d`. That meant the login timeout fix and latest client code never reached the page.

## Version

- Visible version: `v2.3.3`
- Health version: `v2.3.3-pages-local-assets-entry`
