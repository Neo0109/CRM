# v1.7.1 Online Daily Rule Source

Release date: 2026-05-28

## What changed

- Added `docs/SOURCING_RULES_CURRENT.md` as the current human-readable daily-report rule pointer.
- Added `automations/rules/daily-report.json` as the online machine-readable rule source.
- Added `automations/jobs/online_daily_runner.mjs` to load and validate rules before running `online_daily_v4.mjs`.
- Added `docs/CRM_OPTIMIZATION_CONTEXT.md` as a stable handoff note for future CRM optimization conversations.
- Updated the GitHub Actions daily workflow to call the runner and watch rule files.

## Why

Daily-report rules are living product infrastructure. They must live in GitHub and travel with the automation because the operator may switch computers or continue work in a different conversation.

Rules-only changes should not be invisible to automation. The workflow now watches rule documents and the machine-readable rule file, and each run logs the active rule version before generation.

## Remaining work

The V3 generator still contains hard-coded scoring, radar category, media-source, and guardrail logic. Future iterations should move configurable behavior into `automations/rules/daily-report.json` while keeping the generator as execution code.
