# v1.4.2 Pipeline Click Fix

Date: 2026-05-25

## Fix

- Fixed `推进池` row actions where `跟` and `淘` could appear to do nothing.
- The pipeline enhancer no longer intercepts native `跟进` / `淘汰` button clicks.
- Native React state now handles those actions directly, so the selected row and detail panel update immediately.
- The enhancer only intercepts custom actions that the original UI does not have, such as `转观察` / `放入观察`.
- Removed the post-click forced refresh path from enhanced actions, avoiding accidental daily-report re-sync right after a manual user decision.
- Added a visible error alert if a custom action fails to save.
- Updated health check version to `v1.4.2-pipeline-click-fix`.

## Note

If a manually moved lead ever returns to its old bucket after a full page reload, the next fix should preserve human-reviewed bucket decisions during daily report merge.
