# v2.0.3 Sidebar spacing and media sourcing

- Tightened the desktop left sidebar width and padding so navigation no longer leaves excessive blank space.
- Treats domestic media and Bilibili product signals as first-pass CRM leads with original source links, not only Industry Radar background.
- Recognizes edition approval, first reveal, playtest, Demo, trailer/PV, reservation, and domestic studio/publisher context as enough to create a media/Bilibili lead for first-pass review.
- Filters out Bilibili methodology/tutorial videos such as Steam Next Fest signup or wishlist-growth sharing so they do not appear as product leads.
- Adds Bilibili video-search API sources for domestic indie, Demo/playtest, real-machine PV, roguelike/card, and devlog discovery, with search-page fallback when the API is blocked.
- Keeps Steam keyword searches from being treated as domestic proof unless the product/team/publisher evidence itself looks domestic.
- Counts Bilibili, TapTap, indienova, and domestic media originals as valid first-pass verification links.
