# v1.6.1 Cloudflare-managed settings

## Summary

- Removed account, email binding, verification-code, and login password editing from the CRM settings page.
- Kept the settings page focused on Excel export only.
- Moved operational password control to Cloudflare environment variables.

## Password sources

- Login password: `CRM_ACCESS_TOKEN`
- Excel export password: `EXCEL_EXPORT_PASSWORD`

`EXCEL_EXPORT_PASSWORD` now takes priority over any older password stored in CRM settings, so Cloudflare is the source of truth.

## Operator notes

After editing variables in Cloudflare Pages, redeploy the production deployment so the new values are available to Pages Functions.
