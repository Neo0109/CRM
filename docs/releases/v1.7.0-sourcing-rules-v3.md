# v1.7.0 Sourcing Rules V3

Release date: 2026-05-27

## What changed

- Added `docs/SOURCING_RULES_V3.md` as the new output standard for Bilibili BD use.
- Updated the online daily automation to generate Steam Trends as BD decision cards: product data, gameplay, strengths, weaknesses, Bilibili leverage, and next action.
- Updated Industry Radar to use real external media/company/legal signals instead of internal CRM rule notes.
- Added media-source scanning for mainstream game and domestic industry sources, with relevance scoring for gaming, publishing, IP, governance, and Bilibili BD implications.
- Stopped forcing empty radar categories in the frontend; categories without meaningful items are omitted.
- Updated GitHub Actions paths so V3 rule changes trigger the online daily workflow.
- Bumped the visible UI label to `v1.7.0` and `/api/health` to `v1.7.0-sourcing-rules-v3`.

## Product note

- The CRM reader is the Bilibili publishing BD owner. Reports must reduce BD judgment cost, not create more reading burden.
