# v1.8.1 - Sync State Protection and Tab Order

Date: 2026-05-28

## Summary

This release fixes two workflow issues reported during the v1.8 funnel rollout.

## Changes

- Protect manually processed lead workflow state during daily report sync.
- Existing leads now keep their current bucket, stage, priority, owner, due date, calendar flag, review status, and reviewed timestamp when automation enriches the same project again.
- Daily sync can still enrich existing leads with links, contact methods, notes, and other research context.
- Move the `观察池` card before `跟进中` in the review dashboard and bucket filter order.
- Update the visible header version to `Neo's BD Matrix · v1.8.1`.
- Keep the small UI refinement observer stable so it only rewrites the header or controls when the page actually differs.

## Why

The daily report generator can re-emit projects that have already been reviewed. Before this fix, some repeated sync paths could overwrite workflow fields and make processed leads look as if they had moved backward after a deploy or refresh.

The intended behavior is now stricter: automation may enrich an existing lead, but human workflow decisions remain the source of truth.

## Verification Notes

- Code is committed directly to `main` for Cloudflare Pages automatic deployment.
- The frontend ordering update is intentionally small and isolated in the header/UI refinement layer.
