# v1.4.5 Steam link editor

Date: 2026-05-25

## Summary

This release improves the Missing Links workflow. Users can now paste a Steam store link, SteamDB link, Steam community app link, or raw Steam AppID directly in the lead detail panel and save it as normalized Steam links. Missing Links review actions now include a direct Drop option.

## Changes

- Added a clear `Steam 链接补录` panel near the top of the lead detail view.
- Accepted inputs:
  - Steam store app URLs
  - SteamDB app URLs
  - Steam community app URLs
  - raw Steam AppID
- Normalizes any accepted Steam app input into:
  - `https://store.steampowered.com/app/{appId}/`
  - `https://steamdb.info/app/{appId}/`
- Saves the normalized links immediately, so the left-side contact/link column shows `Steam` and `SteamDB` chips after saving.
- Kept Steam game links out of real contact methods, so email/WeChat/phone remain clean.
- Added three fixed actions in Missing Links view: Follow, Watch, Drop.
- Let the pipeline action enhancer skip the fixed Missing Links actions so it does not rewrite them.
- Bumped UI and health versions to `v1.4.5-steam-link-editor`.

## Notes

The older multiline link editor remains available in the product section for bulk links, but Steam app links now have a faster, safer path.
