# v1.2.5 手动新增与 JSON 导入

日期：2026-05-22

## Summary

新增全局“新增 Leads”入口，解决手动补录和 ChatGPT JSON 导入的问题。

## Changes

- 新增右下角全局“新增 Leads”按钮，可在任意页面打开录入面板。
- 支持手动填写单条 lead，并直接写入 Supabase CRM。
- 支持粘贴 ChatGPT 生成的 JSON：单条 lead、lead 数组、`{ "leads": [...] }`，以及 daily report 的 `push_pool / watch_pool / drop_pool`。
- 新增 `/api/import-json` 后端接口，复用现有 `mergeIncomingLeads` 去重与合并逻辑。
- 导入成功后自动刷新页面，让新增/更新 leads 立即出现在 Review 列表。
- 更新 `/api/health` 版本号为 `v1.2.5-manual-lead-import`。

## Notes

- 手动新增的联系方式支持多行输入，一行一个，例如 `Email: team@example.com`、`微信/QQ: example_id`。
- Steam AppID 会继续由后端自动补齐 Steam 与 SteamDB 链接。
