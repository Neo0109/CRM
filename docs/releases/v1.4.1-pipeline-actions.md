# v1.4.1 Pipeline Actions

Date: 2026-05-25

## Changes

- Quick action buttons now adapt to the lead's current bucket instead of showing the same fixed actions everywhere.
- `淘汰池` actions are now recovery-oriented: `放入跟进` and `放入观察`.
- `跟进中` actions are now decision-oriented: `转观察` and `淘汰`.
- `推进池` actions allow demotion or removal: `退回跟进` and `淘汰`.
- `未处理 / 观察池` actions remain initial review actions: `跟进` and `淘汰`.
- Compact row actions now use visible one-character labels (`跟`, `观`, `淘`) instead of misleading fixed icons.
- Updated the health check version to `v1.4.1-pipeline-actions`.

## Funnel Semantics

- `未处理`: all sourced leads awaiting human review.
- `观察池`: directionally relevant, but signal is not strong enough for active BD time.
- `跟进中`: worth continued BD tracking or light outreach, but not yet a committed signing target.
- `推进池`: not a generic recommendation pool. It means the project has a clear internal signal for deeper evaluation, formal BD push, or potential signing.
- `淘汰池`: excluded for now, but can be recovered into `观察池` or `跟进中` if new information appears.
