# v2.7 Monthly Vision Sheet

## Product behavior

- Adds a dedicated `月度视野表` workspace.
- Prefills leads from `待评测`, `测试中`, `跟进中`, and `推进池`.
- Lets the user add other non-dropped CRM leads, remove rows, and edit the monthly snapshot fields.
- Keeps draft and finalized states. Finalized snapshots remain stable when the source lead changes and can be explicitly reopened for correction.
- Exports only finalized snapshots as an Excel-compatible `.xls` file with exactly three columns: `项目名称`, `研发团队`, and `联系方式`.

## Storage and boundaries

- Stores one system row per month in the existing `crm_leads` table with the `__crm_monthly_vision__YYYY-MM` id prefix.
- Does not add a Supabase migration or change the Lead schema.
- Does not change the existing full JSON, CSV, or Excel exports.
- Does not change Daily V4, sourcing rules, generated reports, login, or settings behavior.

## Version

- Visible version: `v2.7`
- Health version: `v2.7-monthly-vision-sheet`
