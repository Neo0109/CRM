# v1.8.0 Funnel Workflow Update

Date: 2026-05-28

## Summary

This release restructures the CRM product logic around a clearer human review funnel:

Unprocessed -> Pending Evaluation -> Testing -> Follow-up / Watch / Dropped.

The goal is to keep sourcing automation broad while keeping human decisions explicit.

## Changes

- Added two new CRM buckets: `待评测` and `测试中`.
- Daily report imports now place qualified sourced leads into the unprocessed review queue instead of automatically routing them into push/watch pools.
- Preserved manually routed buckets during repeated daily syncs so automation does not reset prior human decisions.
- Added priority visual language:
  - High priority: green
  - Medium priority: yellow
  - Low priority: red
- Updated quick actions:
  - `未处理`: `待评测`, `淘汰`
  - `待评测`: `测试中`
  - `测试中`: `跟进`, `观望`, `淘汰`
  - `观察池`: `待评测`, `跟进中`, `淘汰`
  - `淘汰池`: `观望`, `待评测`
- Moving a lead into `测试中` now defaults to a two-week test due date and enables calendar visibility.
- Testing leads past due date show an overdue marker in the list and detail panel.
- Added a detail-panel Due Date confirmation button; leads only appear in the calendar after explicit confirmation.
- Updated displayed header label to `Neo's BD Matrix · v1.8.0`.

## Notes

The workflow intentionally separates automation from human decision-making. Sourcing can still classify report items internally, but CRM entry now starts from a review queue unless a lead is explicitly dropped by the report.
