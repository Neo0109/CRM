# v1.4.8 History Retention

Release date: 2026-05-26

## What changed

- Industry Radar and Steam Trends now keep showing the latest valid report when today's automation has not written a new file yet.
- Added a history picker so busy users can review recent saved reports instead of losing context after midnight.
- Steam Trends history views do not re-sync old CRM candidates; only the default latest view can merge candidates automatically.
- Replaced "waiting for today's automation" empty states with copy that explains there is simply no record for the selected day.
- Bumped the visible UI label to `v1.4.8` and the health endpoint version to `v1.4.8-history-retention`.

## Product note

- Time-based business intelligence should preserve continuity for people, not reset itself at midnight. The UI now treats automation as a source of fresh updates while keeping the previous useful report available until new content arrives.
