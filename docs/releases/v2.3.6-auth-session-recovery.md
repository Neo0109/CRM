# v2.3.6 Auth Session Recovery

发布日期：2026-06-03

## 修复范围

- 修复 Cloudflare Pages 入口函数继续硬编码旧 `v2.3.4` 前端资源的问题，避免生产环境后端已更新但页面仍加载旧 bundle。
- 登录认证清洗用户名和密码中的不可见字符、全角字符、误包裹的中英文引号，并支持用户名大小写不敏感匹配。
- 前端显示名缓存改为绑定到具体用户名，避免旧的 `Neo` 显示名缓存覆盖 `nanyuan`、`yuyang`、`jojo`。
- 普通 API 请求增加超时保护，避免旧 cookie 或网络异常导致页面一直卡住。

## 不变范围

- 不修改日报自动化规则。
- 不修改 sourcing 规则。
- 不修改 Supabase leads 数据结构。

## 验证重点

- `/api/health` 返回 `v2.3.6-auth-session-recovery`。
- 首页 HTML 不再出现 `v2.3.4` 或 `local-assets-v233`。
- `nanyuan` 登录后显示 `南鸢`，`yuyang` 登录后显示 `于老板`，`jojo` 登录后显示 `Jojo`。
