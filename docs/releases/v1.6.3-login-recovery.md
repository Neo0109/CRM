# v1.6.3 Login recovery

## Summary

- Removed the mutation observer from the header UI refinement layer.
- Kept the one-time header version correction and Settings button hiding behavior.
- Updated `/api/health` to report `v1.6.3-login-recovery`.

## Reason

The observer-based header refinement could repeatedly react to DOM changes and make the page feel stuck during login. The refinement now runs once after the app mounts, which is enough for this static header change and avoids browser-side loops.
